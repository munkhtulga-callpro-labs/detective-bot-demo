# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

A Mongolian-language single-page AI detective game. The player solves a mystery in 15 turns by chatting with an n8n-hosted agent. Each turn returns narrative text and (optionally) a generated scene image. The app is designed as a **mobile-first** experience and uses a phone-shaped frame on desktop.

## Commands

- `pnpm dev` — start Vite dev server (http://localhost:5173)
- `pnpm build` — runs `tsc -b && vite build`
- `pnpm lint` — ESLint
- `pnpm preview` — preview the production build
- `pnpm dlx shadcn@latest add <component>` — add a shadcn UI component (writes to `src/components/ui/`)

## Architecture

### Single route, view-state navigation

There is no router. `src/App.tsx` keeps a `view: "home" | "chat"` state and renders either `HomeScreen` or `ChatScreen` inside `MobileFrame`. Navigation between them is just `setView`. "Quit" from the chat returns to home; "Start" creates a fresh game session (a new `sessionId` is generated when `ChatScreen` mounts).

### Mobile frame

`src/components/mobile-frame.tsx` renders a phone-shaped device chrome on `md+` (390×844, rounded bezel, dark page background) and goes full-bleed on smaller screens. **All screens are designed to live inside this frame** — assume a portrait viewport of ~390px wide. Sheets and dialogs portal to `document.body` (Radix default), so they need explicit max-width on `md+` to look contained on desktop (see `history-sheet.tsx`).

### Game session lifecycle

`src/hooks/use-game-session.ts` is the source of truth for an in-progress case:

- `sessionId` is generated by `crypto.randomUUID()` on mount and on `reset()`.
- `send(query)` is the per-turn workhorse: it POSTs to the chat webhook, then **awaits the image fetch** if `image_generation_prompt` is non-empty, then commits both narrative and image in a single `setState`. Text + image are presented together — by design. While the call is in flight, `chat-screen.tsx` shows a loading state with rotating hints; the previous image stays dimmed.
- `history: HistoryEntry[]` accumulates every successful turn for the history sheet.
- Image blob URLs are **retained** for the lifetime of the game (so the history sheet can render previous turn images). `reset()` and the unmount cleanup revoke all of them at once — do not revoke on swap.

### Backend webhooks

Two n8n webhooks under `https://n8n.onlime.mn/webhook/lime/v2/challenge/detective/`:

- `chat` — POST `{ sessionId, query }` → JSON. The response is **double-wrapped** by n8n: `{ "output": { "output": "...", "image_generation_prompt": "...", "turn_number": N, "is_solved", "game_over", "turns_remaining", ... } }`. `src/lib/api.ts:sendChat` unwraps the outer `output` key. Don't remove that unwrap unless you've verified the backend has been flattened, otherwise React will crash trying to render an object as a child.
- `generate-image` — POST `{ image_generation_prompt }` → binary PNG. Consumed as a blob and exposed as an object URL.

If the image request fails the error is swallowed and the previous image is kept — the chat must not block on image generation. If the chat request fails, the hook surfaces `state.error` and `retry()` replays the last query.

### Styling

- **Tailwind v4** via `@tailwindcss/vite`. All theme tokens (colors, fonts, radii) live in `src/index.css` under `@theme inline`. The noir palette is defined there as `noir-bg`, `noir-surface`, `noir-border`, `noir-cream`, `noir-amber`, `noir-amber-soft`, `noir-danger` — prefer these over arbitrary hex values when adding new UI. Fonts: `font-sans` (Inter), `font-serif` (Lora, used for narrative + titles).
- **shadcn UI** (style: new-york, baseColor: neutral, lucide icons). Generated components in `src/components/ui/` should generally be left untouched — restyle by passing `className` from the call site. `cn()` helper in `src/lib/utils.ts`.
- Tailwind v4 canonical class names: prefer `bg-linear-to-b` over `bg-gradient-to-b`, `wrap-break-word` over `break-words`, `max-w-70` over `max-w-[280px]`. The linter will flag the non-canonical forms.
- The `fadeUp` keyframe in `index.css` is used for per-turn narrative transitions. The animation re-fires by changing a React `key` on the `<p>` (state-based, not ref-based — refs don't trigger re-renders).

### Path alias

`@/*` → `src/*`, configured in both `vite.config.ts` and the tsconfigs. Note: `baseUrl` is intentionally *not* set (deprecated in TS 6+); `paths` works standalone under `moduleResolution: "bundler"`.

### Localization

The UI is in Mongolian. There is no i18n library — strings live inline in components. The backend agent must also respond in Mongolian; if you see English narrative coming back, it's a system-prompt issue on the n8n side, not the frontend.
